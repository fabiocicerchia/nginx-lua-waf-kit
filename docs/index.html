🛡️ nginx-lua-waf-kit

Opt-in Lua modules for the nginx-lua image: rate limiting, bot scoring, edge JWT, geo/ASN policy and request mirroring.

An opt-in Lua module set for the existing nginx-lua image — a kit, not a WAF product. Versioned tag-for-tag against nginx-lua releases so existing users adopt it incrementally.

Install
git clone https://github.com/fabiocicerchia/nginx-lua-waf-kit.git \

or: /opt/nginx-lua-waf-kit
